# Rapports d'exécution

Un rapport est créé par instance et par date, selon le modèle [_template.md](_template.md) :

`<profil>-<YYYY-MM-DD>.md`

Exemple : `rpbm-preprod-2026-08-07.md`.

Le rapport contient les IDs Odoo, les états, les quantités préparées, les deltas attendus et les
documents persistants. Il ne contient aucun secret.

Ne pas remplacer un ancien rapport : une nouvelle exécution crée un nouveau fichier ou une nouvelle
version explicitement datée.
