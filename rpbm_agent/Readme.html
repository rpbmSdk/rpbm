Objectif

Outil de récupération des données des portails XGlass et VSF pour intégration dans le processus de vente

Pré requis

  • Créer les paramètres systèmes ir.config_parameter pour la connexion aux portails XGlass et VSF :
    • XGLASS_USER : Utilisateur du portail XGlass
    • XGLASS_PASS : Mot de passe du portail XGlass
    • VSF_LOGIN : Utilisateur du portail VSF
    • VSF_PASSWORD : Mot de passe du portail VSF Note : Ces paramètres peuvent être créés par script ou manuellement dans l'interface d'administration d'Odoo.
  • Pour une utilisation optimale du module, il est nécessaire de créer les champs destinés à recevoir les données des portails XGlass et VSF :

Véhicule

Modèle : fleet.vehicle

Chemin :

Champs à créer (manuellement ou par script) :

  • x_studio_detail_model : Détail du modèle (ex: KIA PICANTO III PHASE 2 - 5P 2020-09-> 1.2i 85)
  • x_studio_date_mec: Date de mise en circulation (ex: 2020-09-01)
  • x_studio_autre_infos : Autres informations (actuellement non utilisé)
  • x_studio_note : Champ HTML calculé qui permet d'afficher les informations générales du véhicule (ex: Détail du modèle, Date de mise en circulation, VIN, Autres informations, etc.)

Piste / Opportunité

Modèle : crm.lead Chemin :

Champs existants modifiés :

  • x_studio_field_NVioD : Champ Immatriculation, on conserve ce champ dans l'architecture car il est lié à beaucoup d'autres (immatriculation dans les factures, ordres de vente, etc). En revanche on le rend calculé, dépendant de x_studio_vehicle_id pour récupérer l'immatriculation du véhicule associé.
  • x_studio_field_KyCjB et x_studio_field_ZhaeY : Champs pour les informations de marque et modèles de véhicules. Initialement ces champs étaient des champs liés à des modèles personnalisés, mais ils n'ont pas étés tenus avec rigueur (doublons, créations de nouveaux modèles, etc.). On les rend donc obsolètes en les marquant comme tels par l'ajout d'un de la mention '[Obsolète]' dans leur nom.

Champs à créer (manuellement ou par script) :

  • x_studio_vehicle_id : Champ Many2one vers le modèle fleet.vehicle pour lier la piste à un véhicule
  • x_studio_categorie_xglass : Champ pour la catégorie Xglass (ex: Pare-brise, Optique, etc.)
  • x_studio_base_eurocode : Champ pour la base Eurocode (ex: 123456)

Ordre de vente

Modèle : sale.order Chemin : Champs à créer (manuellement ou par script) :

  • x_studio_vehicle_id : Champ Many2one vers le modèle fleet.vehicle pour lier la commande à un véhicule, lié au champ x_studio_vehicle_id de la piste
  • x_studio_categorie_xglass : Champ pour la catégorie Xglass (ex: Pare-brise, Optique, etc.), lié au champ x_studio_categorie_xglass de la piste
  • x_studio_base_eurocode : Champ pour la base Eurocode (ex: 123456), lié au champ x_studio_base_eurocode de la piste

Utilisation

Généralités

Le widget est ajouté à la vue formulaire via la balise <widget name="rpbm_agent_widget" />. Il est possible de le placer dans n'importe quelle vue formulaire d'un modèle Odoo et est symbolisé par une icône représentant une loupe (🔍).

Lorsqu'un utilisateur clique sur l'icône, le widget affiche une fenêtre de dialogue et déclenche le chargement suivant :

  1. Chargement des agents : Pour chaque agent (Xglass et VSF), le système va se connecter aux portails respectifs
  2. Récupérations des données de l'enregistrement en cours : Le système va récupérer les données du modèle Odoo en cours (Piste/Opportunité ou Ordre de vente) et essayer de charger les informations associées :
    1. Récupération de l'immatriculation sur le modèle Odoo. Si elle n'est pas renseignée, l'utilisateur peut la saisir manuellement et cliquer sur le bouton "Rechercher" pour lancer la recherche
    2. Si l'immatriculation est renseignée, le système va essayer de récupérer depuis Xglass les informations du véhicule
      • Une fois les informations du véhicule récupérées, le système va afficher les différentes véhicules disponibles dans le widget (si multiple véhicules)
      • L'utilisateur peut sélectionner le véhicule souhaité en cliquant dessus, la case se colore alors en bleu clair.
      • Pour chaque véhicule, le système va vérifier si le véhicule est déjà enregistré dans Odoo (recherche par immatriculation), si ce n'est pas le cas, il est possible de l'enregistrer en cliquant sur le bouton "Créer" (Note : Méthode à mettre à jour pour ajout du conducteur), sinon le widget précise que le véhicule est déjà enregistré et propose un bouton "Voir" pour ouvrir le formulaire du véhicule
    3. Une fois le véhicule sélectionné, récupération de la Planche Xglass qui contient les différentes catégories de pièces disponibles pour le véhicule (peut être déclenché par l'utilisateur)
    4. Récupération de la catégorie sur le modèle Odoo, si elle n'est pas renseignée, l'utilisateur peut la saisir manuellement en cliquant sur la catégorie souhaitée.
    5. Lorsque la catégorie est sélectionnée, le système va essayer de récupérer depuis Xglass les Pièces Xglass disponibles et les afficher dans le widget
    6. L'utilisateur peut sélectionner la pièce souhaitée en cliquant dessus, le système va alors récupérer la base Eurocode associée à la pièce et l'afficher dans le champ de recherche Eurocode
      • Il est possible que la pièce n'ait pas de base Eurocode associée, dans ce cas, le champ Eurocode sera vide
    7. Si la base Eurocode est renseignée, le système va essayer de récupérer depuis VSF les pièces VSF disponibles et les afficher dans le widget

Piste / Opportunité

En cliquant sur confirmer, le système va :

  1. Enregistrer le véhicule sélectionné dans Odoo, si ce n'est pas déjà fait
    • Lors de la création du véhicule, le système va remplir les champs x_studio_detail_model, x_studio_date_mec, x_studio_autre_infos et x_studio_note, vin_sn, driver_id, model_id, license_plate, power, doors,fuel_type et image_1920 avec les informations récupérées depuis Xglass
  2. Lier le véhicule à la piste/Opportunité en remplissant les champs x_studio_vehicle_id, x_studio_categorie_xglass et x_studio_base_eurocode
  3. Fermer la fenêtre de dialogue et mettre à jour la vue formulaire avec les informations du véhicule sélectionné

Ordre de vente

Une fois les Pièces VSF sélectionnées, l'utilisateur peut créer les pièces dans la base de données Odoo en cliquant sur le bouton "Créer" ou ouvrir le formulaire de la pièce en cliquant sur le bouton "Voir" (si la pièce est déjà créée dans Odoo). Lors de la création de la pièce, le système va :

  1. Enregistrer la pièce en tant qu'Article (product.template) stockable avec en tant que prix de vente le prix récupéré depuis VSF, avec la référence de la pièce VSF
  2. Ajouter le prix de vente VSF dans les prix fournisseurs de l'article

Méthodes

Création de véhicule

Lors de la création du véhicule, le système va effectuer les actions suivantes :

  • Création de la 'Marque de véhicule' si elle n'existe pas déjà dans la BDD
  • Création du 'Modèle de véhicule' si il n'existe pas déjà dans la BDD
  • Ajout du VIN dans le champ vin_sn
  • Ajout de la date de Mise en circulation dans le champ x_studio_date_mec
  • Ajout du type de carburant dans le champ fuel_type, si le type de carburant n'existe pas dans la sélection alors il est créé
  • Ajout de l'image dans le champ image_1920
  • Ajout du conducteur dans le champ driver_id (récupéré depuis l'enregistrement en cours, champ Client)
  • Ajout de la puissance dans le champ power
  • Ajout du libéllé court (ex. SUZUKI BALENO II - 5P 2016-04-> 1.2i 90) dans les champs description et x_studio_detail_model
  • Ajout du nombre de portes dans le champ doors

Création d'Article

Lors de la création d'un Article le système va effectuer les actions suivantes :

  • Création de l'Article en tant que produit (product.product) avec les informations récupérées depuis VSF :
    • Ajout du nom de l'article dans le champ name
    • Ajout de la référence de l'article dans le champ default_code
    • Ajout du prix de vente dans le champ list_price
    • Ajout de la description de l'article dans le champ description
  • Ajout dans l'article d'un Prix fournisseur avec les informations récupérées depuis VSF :
    • Ajout du prix fournisseur dans le champ price
    • Ajout du fournisseur dans le champ partner_id (ID VSF = 5708)
    • 'delay' = 1
